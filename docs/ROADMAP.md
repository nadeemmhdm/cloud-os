# Roadmap

## Current development
- Complete management UI for Files, Terminal, Teams, Backups, Network, Security, and Settings.
- Windows and Linux end-to-end installation/autostart tests.
- Cloudflare and SSH setup workflow.
- Automated API/RBAC security tests.

## Planned
- Signed/checksummed update and rollback flow.
- Scheduled backups and restore UI.
- Application/process manager.
- Website hosting manager.
- Notifications and health watchdog improvements.
- PWA/mobile experience.
- Storage pools and quotas.
- Optional plugin architecture.

Roadmap items are plans, not guarantees of current functionality.
