# Support

For bugs, include your Cloud OS version, operating system, Python version, the command that failed, relevant sanitized logs, and the output of `cloud-os doctor`.

Before sharing logs, remove passwords, session cookies, Cloudflare credentials, SSH private keys, access tokens, hostnames you consider private, and personal file names.

Use GitHub issues for reproducible project bugs and feature requests. Security vulnerabilities should follow SECURITY.md instead of a public issue.
