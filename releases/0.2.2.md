# Cloud OS v0.2.2 — SSH, Terminal & AI Chat Update

Cloud OS 0.2.2 is a patch release focused on remote server management and the built-in AI experience.

## Highlights
- Role-gated Cloud OS SSH server shell.
- Native PowerShell on Windows and Bash on Linux.
- Stateful dashboard terminal working-directory sessions.
- General-purpose Cloud OS AI chat for normal questions, coding, debugging and server help.
- Automatic AI provider selection; no provider selector in the chat widget.
- AI configuration remains restricted to authorized Settings users.
- Windows and Ubuntu security/test matrix verified before release preparation.

## Update
Run:

    cloud-os update-check
    cloud-os update

Then restart Cloud OS if it is already running.

## Security note
Cloud OS does not bypass Windows UAC or Linux sudo authorization. Effective administrative authority remains controlled by the host operating system in addition to Cloud OS RBAC.
