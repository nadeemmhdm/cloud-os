# Cloud OS 0.2.0

Status: release-note draft for the current package version. This file does not create or imply a published GitHub Release.

## Summary
Security and administration update adding team RBAC, host-native terminal behavior, stronger authentication controls, safer file handling and broader diagnostics.

## Added
- Owner, Admin, Operator, Member and Viewer access model.
- User/team management and effective permissions.
- Host-native terminal: PowerShell on Windows and Bash on Linux.
- Role-aware privileged-terminal requests that respect host OS authorization.
- Terminal shell discovery API.
- Login throttling and stronger PBKDF2 password hashing.
- Backup listing/creation, audit API and integration diagnostics.
- Windows and Linux CI test matrix.

## Security
- Owner role reserved for the built-in primary owner account.
- File APIs restricted to the configured storage root.
- Upload size limit and partial-file cleanup.
- Root storage deletion protection.
- Terminal uses explicit executable arguments with shell=False.
- Unknown shells are rejected.
- Windows UAC is never bypassed.
- Linux privileged mode requires non-interactive sudo authorization.
- Host SSH service is not silently started or modified.
- Corrupt access-control database now fails closed.
- Audit entries are bounded, protected on POSIX and rotated.
- Backup directory names include collision-resistant suffixes.
- Terminal timeouts are handled explicitly.

## Current limitations
- Windows autostart is logon-triggered, not a pre-login production service.
- Linux system-wide autostart remains intentionally disabled until a safe unprivileged service design is completed.
- Full dashboard UI is still incomplete.
- Sessions and login throttling are process-local/in-memory.
- CSRF/origin hardening and signed/checksummed update artifacts remain future work.
- Direct public Internet exposure is not recommended; use authenticated TLS/tunnel access.
