# Cloud OS v0.3.0 — Recovery, Security & Lifecycle Update

Cloud OS 0.3.0 is a feature release focused on safer day-to-day server operation, recovery, authentication hardening and lifecycle management.

## Highlights
- Verified full Cloud OS backup and restore workflow for configured storage and Cloud OS state.
- SHA-256 manifest integrity verification for new-format backups.
- Automatic pre-restore safety backup and best-effort rollback protection.
- Protected latest backup with controlled deletion of older backups.
- Persistent progressive login cooldowns for web authentication, with account and IP tracking.
- SSH password authentication throttling.
- Restored persistent dashboard terminal sessions and improved terminal error reporting.
- Native host-shell SSH integration remains role-gated by Cloud OS permissions.
- Live dashboard user clock, date and browser timezone display.
- Collapsible icon-only navigation rail and refreshed dashboard interactions.
- Animated Cloud OS AI identity and updated visual branding.
- Safe CLI updater with visible operation stages, dirty-checkout protection, installation verification and rollback attempt.
- New confirmed `cloud-os uninstall` command with data-preserving defaults.
- Updated website, documentation, security guidance and error-code library.

## Update workflow

    cloud-os update-check
    cloud-os update

The updater now reports real stages for checking, fetching, preparing, installing and verifying. After success it prints the installed version, Git revision and update channel.

Development/testing only:

    cloud-os update --source main

## Uninstall

    cloud-os uninstall

Cloud OS configuration, backups and configured storage are preserved by default.

Non-interactive uninstall:

    cloud-os uninstall --yes

Permanent data removal must be requested explicitly:

    cloud-os uninstall --purge-data

## Security
- Repeated web login attempts use persistent progressive cooldowns which survive Cloud OS restart.
- SSH password attempts are throttled.
- Public health output no longer exposes the Cloud OS version.
- The updater refuses to overwrite a source checkout with local changes.
- State-changing browser operations retain same-origin enforcement and RBAC.
- Windows UAC is not bypassed; terminal commands inherit the privileges of the Cloud OS process.

## Backup scope
The full recovery package covers the configured Cloud OS storage plus Cloud OS state files such as configuration, access-control data, audit log and AI provider secrets when present. It is not a Windows/Linux bare-metal image and does not capture host applications, boot partitions or the entire operating system.

Backup packages are currently local directory-based recovery data and are not encrypted archives. Treat backup storage as sensitive.

## Known limitations
Signed/checksummed release artifacts, encrypted/off-device backup packaging, SSH key authentication, persistent distributed sessions, hardened Windows secret ACLs and a least-privilege pre-login Windows service architecture remain future hardening work.

## After updating

    cloud-os doctor

Restart a running Cloud OS process after the update so the new package is loaded.
