# Cloud OS 0.1.0

Status: historical release-note draft. This file does not create or imply a published GitHub Release.

## Summary
Initial Cloud OS foundation for turning an existing Windows or Linux computer into a lightweight self-hosted personal cloud server without replacing the host operating system.

## Included
- FastAPI application and basic responsive system dashboard.
- CPU, memory, storage and uptime reporting.
- Persistent Cloud OS configuration and isolated storage root.
- File listing, upload, download, folder creation and deletion foundations.
- Owner authentication with salted password hashing and expiring sessions.
- Basic audit logging, backup and diagnostics foundations.
- SSH and Cloudflare integration/status foundations.
- Windows and Linux installation foundations.

## Security baseline
- Storage-root path containment.
- Authenticated management API foundation.
- Passwords are not stored in plaintext.
- Development warning against direct public Internet exposure.

## Known limitations
- Dashboard management UI incomplete.
- Autostart/service behavior not production-complete.
- Terminal, RBAC, update verification and Internet-facing deployment required further hardening.
