SELF-HOSTED PERSONAL CLOUD

Turn your computer into your own cloud.

Cloud OS is a lightweight management layer for Windows 10/11 and Linux with a responsive dashboard, restricted storage, RBAC, backups, diagnostics, terminal access and optional AI-assisted help.

Get startedRead documentation
Dashboard

Desktop to mobile

Animated macOS-inspired interface designed for desktop, tablet and phone access.

Access

Roles, users and teams

Owner, Admin, Operator, Member and Viewer permissions keep capabilities separated.

Operations

Files, backups and diagnostics

Manage restricted storage, create backups, inspect system health and use host-native terminal tooling.

Security by boundaries, not promises.

Cloud OS separates authentication from authorization and keeps filesystem access inside a configured storage root.

Authentication

Salted PBKDF2 password hashes, expiring sessions, login throttling and same-origin checks for state-changing browser requests.

Least privilege

Terminal and management capabilities are permission-gated. Windows UAC is never bypassed.

Remote access

Keep the app private or place it behind authenticated HTTPS/TLS access such as a properly configured tunnel or reverse proxy. Do not directly expose the development HTTP port.

AI Help, optional by design.

Configure one supported provider: Gemini, OpenAI, Claude or Ollama Cloud. Cloud OS uses local project documentation as reference context for troubleshooting; this is retrieval/context grounding, not model fine-tuning. API keys stay server-side.

Install Cloud OS

Review the installer before running remote scripts. Administrator/root permission and Internet access are required during installation.

Windows 10/11

irm https://raw.githubusercontent.com/nadeemmhdm/cloud-os/main/install.ps1 | iex

Linux

curl -fsSL https://raw.githubusercontent.com/nadeemmhdm/cloud-os/main/install.sh | bash

Core commands

cloud-os setup cloud-os start cloud-os status cloud-os doctor cloud-os version cloud-os update-check cloud-os update

Windows startup is currently logon-triggered rather than a pre-login service. The Linux development installer does not enable a root system service.
