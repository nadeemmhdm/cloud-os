SECURITY MODEL

Boundaries before convenience.

Cloud OS combines authentication, permission checks and storage isolation. Internet-facing deployments should still sit behind properly configured HTTPS/TLS access.

Authentication

Salted password hashing, expiring sessions, persistent progressive web/SSH login cooldowns and same-origin mutation checks.

Least privilege

Management and terminal capabilities are role-gated. Windows UAC is never bypassed.

Storage boundary

File operations stay inside the configured Cloud OS storage root.
